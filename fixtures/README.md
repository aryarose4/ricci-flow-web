# flow-fixtures: golden data from the /flow page pipeline

Generated by `python -m singular_ricci.dev.scratch.export_flow_fixtures --out singular_ricci/dev/artifacts/flow-fixtures`
(~70 s for 6 configs x 2 runs; second run is the determinism check, all arrays bit-identical, NaN==NaN).

Pipeline reproduced: `flow_stream.run_flow(request)` with `realizer="true_flow"` (True Ricci Flow, default
`trf_realizer="fast"`), `resolution="smoke"` (mesh (N,m,K)=(150,12,2)), seed_surface gluing|smart|polytope.
rho<0 goes through `run_flow_true_negative` (intrinsic flow + 3D tracking, "stage 2").

## Layout
`manifest.json`: per config summary, GB max, quality label, file sha256, determinism, total runtime.
`<name>/fixture.json`: `meta` (request, mesh level, solver settings) and `scalars` (per-frame scalars, quality note).
`<name>/arrays.npz`: arrays below. nf = 21 frames, nv = vertices, ne = edges.

## Conventions
- Sphere coordinates: `sphere_vertices` (nv,3) unit sphere, outward faces `sphere_faces`. Input `positions` are
  stereographic-plane (x,y) cone locations (n-gon radius ~0.7); `betas` = alpha/(2 pi). Cone vertex ids = `cone_ids`.
- Metric on the sphere mesh: edge length `L = exp((u_i+u_j)/2) * L0` (`L0` = round-sphere chord lengths), i.e.
  conformal factor u with metric e^{2u} g_round-chord convention at vertices; BDF2 adaptive time stepping,
  cone defects pinned to `2 pi (1-beta_i)`. Gauge: u is the flow's own state (area normalised at the seed;
  `diagnostics` area field not fixed to 4 pi except via gauge()); rho is an OUTPUT: `rho = C / (smooth-vertex area)`,
  C = 4 pi - sum cone defects. Model subtraction is NOT used in the intrinsic flow (u is the full log factor); only
  `cf_w` (display raster) uses `viz.w_interp.smooth_w_grid` (cone model + smooth remainder).
- Frame times: `default_times()` (t up to 16, 12 early + 8 late); frame 0 is the seed metric, last is the uniformized end.
  3D realization is computed BACKWARD from the uniformized end (`realize_backward`), frame 0 additionally from `clean_start`.

Quality note (`scalars.quality`): `flow_quality` thresholds len rms 1 %, max 5 %, no deep folds (polytope opening folds exempt).

## Meaningful tolerances (suggested)
- Intrinsic: mesh, L0, cone ids: exact / 1e-12. `u`, `L`, `K_defect`, `rho`: rel 1e-8 (Newton tol 1e-11; BDF2 step
  control must be replicated or `t`-grids compared at output times only, ~1e-6 if step sequence differs).
- GB residual: both sides below 1e-12 (observed <= 9e-14); do not compare residuals to each other, assert magnitude.
- 3D `vertices3d`: NOT a unique target (LM fit, warm-start path dependent). Compare invariants after rigid alignment (Kabsch): edge length error <= 5e-3 (observed typical ~2e-3), `len_rel_*` agree within 1e-3 abs, fold counts within +-2, quality label equal.
- `cf_w`: abs 1e-3 (display raster, 5 significant digits, RBF smoothing).
- The rho<0 case ends "Best Attempt": that label is the expected golden outcome, and its 3D part is least stable.
- Not certificates: C/R cone-angle diagnostic for beta <~ 0.5; use GB and K=rho.
